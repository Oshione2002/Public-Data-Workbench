How the work moves

The interface changes with the task: search when you are discovering, compare when sources conflict, then switch to a dense workbench once the dataset exists.

Discover

Search locally indexed metadata across providers without waiting for every external API.

Compare

See definitions, units, frequency, coverage and original producer before adding a series.

Resolve

If one source is incomplete, compare compatible candidates and build a composite only when the evidence supports it.

Prepare

Merge, reshape and transform while preserving source codes and a transformation log.

Export

Download the data together with the metadata needed to reproduce the research.
